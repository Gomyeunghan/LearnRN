# 2026-09-09 React Native 학습 정리

## 오늘 학습한 내용

1. **Android Studio 로컬 에뮬레이터 환경 구성**
   Android Studio를 설치하고 로컬 PC에서 Virtual Device(AVD)를 사용해 안드로이드 에뮬레이터를 띄워 앱을 실행하는 환경을 구성했다.

2. **기본 프로젝트에 TypeScript 환경 적용**
   `App.js`/`index.js`를 `App.tsx`/`index.tsx`로 전환하고 `tsconfig.json`을 추가해 TS 환경을 적용했다. `package.json`의 `main` 필드도 `index.tsx`로 변경.

3. **RN의 CSS 속성은 상속되지 않는다**
   웹 CSS와 달리 React Native의 스타일 속성은 부모에서 자식으로 상속되지 않는다. 각 컴포넌트마다 필요한 스타일을 명시적으로 지정해야 한다.

4. **태그(컴포넌트)마다 사용 가능한 속성이 다르다**
   `View`, `Text`, `TextInput` 등 컴포넌트별로 지원하는 props가 다르므로, 공식 문서를 참고하며 하나씩 확인하고 있다.

5. **`TextInput`의 `onChangeText`는 이벤트 객체 없이 값을 바로 전달한다**
   `onChange`와 달리 `onChangeText`는 이벤트 객체를 거치지 않고 입력된 텍스트 값을 콜백의 인자로 바로 넘겨준다.
