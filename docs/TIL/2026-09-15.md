# 2026-09-15 React Native 학습 정리

## 오늘 학습한 내용

1. **상태 끌어올리기(state lifting)로 화면 전환하기**
   `App.tsx`에 `userNumber` state를 두고, 사용자가 숫자를 선택하기 전에는 `StartGameScreen`을, 선택한 이후에는 `GameScreen`을 조건부로 렌더링하도록 만들었다. 자식 컴포넌트(`StartGameScreen`)에서 발생한 값을 부모가 알아야 할 때는, 부모가 콜백 함수(`onPickNumber`)를 props로 내려주고 자식이 그 함수를 호출해 부모의 state를 갱신하는 패턴을 사용한다는 것을 연습했다.

2. **`Button` 컴포넌트를 진짜 재사용 가능하게 만들기**
   기존에는 `Button` 내부에서 `onPress={() => console.log("press")}`처럼 동작이 하드코딩되어 있었다. 이를 `onPress` 함수를 props로 받아 `Pressable`에 그대로 전달하도록 바꿔서, 같은 `Button` 컴포넌트를 "Reset"과 "Confirm"처럼 서로 다른 동작에 재사용할 수 있게 되었다.

3. **`TextInput`을 제어 컴포넌트(controlled component)로 다루기**
   `enteredNumber` state와 `value`, `onChangeText`를 함께 연결해서 입력값을 React state로 완전히 제어하도록 했다. Reset 버튼을 누르면 state를 빈 문자열로 초기화하는 것만으로 입력창이 비워지는 걸 보고, `value`를 state에 바인딩해두면 컴포넌트 바깥에서도 입력값을 강제로 바꿀 수 있다는 걸 확인했다.

4. **`Alert.alert`로 입력 값 검증하기**
   `parseInt`로 변환한 값이 `isNaN`이거나 1~99 범위를 벗어나면 `Alert.alert`를 띄워 사용자에게 알려주고, 알림의 버튼 `onPress`에 리셋 핸들러를 연결해서 확인을 누르면 입력이 초기화되도록 만들었다. `Alert.alert`의 버튼 배열에 `text`, `style`, `onPress`를 채워 넣는 방식으로 네이티브 알림 UI를 커스터마이징할 수 있다는 것을 익혔다.
