# 2026-09-14 React Native 학습 정리

## 오늘 학습한 내용

1. **새 실습 프로젝트로 전환 (숫자 맞추기 게임)**
   기존 할일 앱(`TodoInput`, `TodoItems`)을 정리하고, `screens/` 폴더를 새로 만들어 화면 단위(`StartGameScreen`, `GameScreen`, `GameOverScreen`)로 코드를 나누는 구조를 연습했다. `App.tsx`는 각 화면을 조립하는 최상위 컨테이너 역할만 하도록 단순화했다.

2. **재사용 가능한 `Button` 컴포넌트 - 이중 `View`/`Pressable` 구조**
   그림자(shadow)와 리플/눌림 클리핑을 동시에 적용하려고 하면 한 요소에서 충돌이 난다. `overflow: "hidden"`을 그림자가 있는 View에 걸면 그림자 자체가 잘려서 사라지기 때문이다. 이를 해결하기 위해 바깥쪽 `View`(그림자 담당)와 안쪽 `Pressable`(`overflow: hidden`으로 리플/눌림 효과 클리핑 담당)로 역할을 분리하는 패턴을 학습했다.

3. **`TextInput`으로 숫자 입력받기**
   `keyboardType="number-pad"`로 숫자 전용 키보드를 띄우고, `maxLength`로 입력 자릿수를 제한했다. `autoCapitalize="none"`, `autoCorrect={false}`를 함께 꺼서 숫자 입력에 불필요한 자동완성/자동대문자 동작을 막았다.

4. **안드로이드/iOS 그림자 처리 방식 차이 복습**
   iOS는 `shadowColor`, `shadowOffset`, `shadowOpacity`, `shadowRadius` 조합으로, 안드로이드는 `elevation` 값 하나로 그림자를 표현한다. 두 플랫폼 모두 대응하려면 스타일에 두 세트를 함께 선언해야 한다는 점을 다시 확인했다.
