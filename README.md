# RnLearn

React Native(Expo) 학습용 저장소입니다. Expo + TypeScript로 구성되어 있습니다.

## 기술 스택

- Expo `~57`
- React Native `0.86`
- React `19`
- TypeScript

## 시작하기

```bash
npm install
npm start        # Expo 개발 서버 실행
npm run android  # 안드로이드 에뮬레이터/기기에서 실행
npm run ios      # iOS 시뮬레이터에서 실행
npm run web      # 웹에서 실행
```
